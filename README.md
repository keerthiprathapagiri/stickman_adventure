# Stickman Adventure
React + Vite + Canvas platformer inspired by Bounce.
```
npm install
npm run dev     # open the printed URL
npm run build   # production build
```
Controls: A/D or ←/→ move, Space/↑/W jump (hold = higher), Esc pause. Touch buttons appear on mobile.
Stars: 1 for finishing, 2 for 60%+ coins, 3 for all coins plus the hidden gem.
